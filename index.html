تقرير أساسيات تصميم وتنسيق المواقع باستخدام لغة CSS

اسم الطالب: احمد سعد عبد الغني

الرقم الجامعي: 2503203

المقدمة

تُعد لغة CSS (Cascading Style Sheets) الأساس الجوهري في تصميم وتنسيق صفحات الويب، حيث تُستخدم للتحكم في مظهر الصفحات، الألوان، الخطوط، وتوزيع العناصر بشكل متجاوب يتناسب مع مختلف الشاشات والأجهزة.

عرض الموضوع

كيفية تغيير تصميم الخطوط والمظهر

من خلال خصائص CSS، يمكننا تعديل مظهر النصوص والعناصر بكل سهولة لتحسين تجربة المستخدم. يوضح الجدول التالي مقارنة بين بعض خصائص التنسيق الشائعة:

خاصية الـ CSS الوظيفة الأساسية مثال استخدامه
color تغيير لون النص تحديد لون الخط للعنوان الرئيسي
font-family تغيير نوع خط التنسيق تخصيص نوع الخطوط المستخدمة بالموقع
background-color تغيير لون خلفية العناصر تلوين خلفية الصفحة أو الجداول
